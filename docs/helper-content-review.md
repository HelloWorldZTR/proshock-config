# Portal Helper 作用说明（已实现）

本轮保留并实现 **14 项：P0 11 项、P1 3 项**。文案与取舍以本次校对为准；R11 及按键、摇杆形状、模拟校准页的候选项已移出本轮。中英文文案集中在 `src/help-content.js`，页面只声明稳定 ID。

## 文案原则

Helper 要回答：**我改这个，手柄会怎样？什么时候值得改？有什么代价？** 先写结果，再写适用场景或代价。不要把英文标签翻成中文后再解释一遍，也不要把 `ADC`、`Q1.15`、`RC` 等内部名词当作答案。每个弹窗以一到两句为宜；较长的操作步骤留在可见说明或指南中。

## 配置 → 系统（7 项）

| ID | 优先级 | 按钮位置 | 拟显示的解释 |
| --- | --- | --- | --- |
| R01 | P0 | Apply / Save | Apply改动断电丢失，如果想要保存需要先apply再save |
| R02 | P0 | Poll rate | 更高的轮询率带来更低的延迟，也会增加电脑的负担 |
| R03 | P0 | Button debounce | 更低延迟更低，但是可能导致一次按键被识别为多次 |
| R04 | P1 | Boot profile | 把最常用的槽位设为开机默认值，之后每次上电会自动选它。修改这个选项不会立刻切换当前槽位。 |
| R05 | P0 | Ribbon mode | 安装HML排线需选择该选项为HML模式，根据安装的扳机类型可能需要反转扳机并校准。 |
| R06 | P0 | Sampling depth | 越高的采样深度可以识别摇杆越精细的变化，摇杆本身的精度是有限的。 |
| R07 | P0 | Hardware directions / Invert | 如果安装了非默认PS4摇杆可能需要反转对应的方向。 |

外置 ADC 当前不可选，页面已写明原因，不为这个禁用项再加 Helper。R05 可在“附件中心 → FPC2”复用；R07 可在“校准 → 手动设置”和 FPC2 的扳机方向处复用。

## 配置 → 摇杆 / 扳机响应（3 项）

| ID | 优先级 | 按钮位置 | 拟显示的解释 |
| --- | --- | --- | --- |
| R08 | P0 | Inner deadzone | 摇杆漂移了可以设置一些内死区，否则可以不设置。 |
| R09 | P0 | Outer deadzone | 可以通过外死区实现摇杆更早打满的效果。 |
| R10 | P1 | 曲线预设 | 摇杆旋转的角度和输出的数值之间的关系。横轴表示摇杆的实际输入，纵轴表示手柄的输出。可以实现各种手感。 |

“Stick response 是 radial”已在页头说明，当前不单独加一个重复的问号；如果用户仍误以为 X/Y 可分别调曲线，可把这句补进 R11。

## 配置 → RC（4 项）

| ID | 优先级 | 按钮位置 | 拟显示的解释 |
| --- | --- | --- | --- |
| R12 | P0 | Smoothing / Smoothing cutoff | 去除高频的抖动（一般为摇杆机械噪声和电气噪声） |
| R13 | P0 | Boost | 增加摇杆推动的反应速度。 |
| R14 | P1 | Fast cutoff / Slow cutoff | 这两个值决定 Boost 对多快的动作最明显。先保留默认值；若短促动作增强得过头或不明显，再拉近或拉开两者的差距，并用下方曲线比较。 |
| R15 | P0 | Boost gain | 调高会加重 Boost 的效果；设为 0 则不增加这部分响应。建议从小值逐步上调，若出现冲过目标或抖动，就回退。 |

RC 页已加入“恢复初始设置”按钮，只重置当前选中的摇杆；它修改当前草稿，仍需 Apply、Save 才能持久化。这是独立的界面改动，不作为 Helper 文案。

RC 页面现有的游戏/赛事风险提示必须继续常显，不能藏入 Helper。频率图中的 dB 是参数预览，不建议先为图表术语增加第五个弹窗。

## 本轮不加 Helper 的配置页

- 按键、组合键和宏：会用这些功能的人不需要解释。
- 高级摇杆形状：会用这些功能的人不需要解释。
- 模拟校准：不需要解释。

Coverage、Target error 和 ±5% 颜色是测试结果，不是可配置项；本轮不在它们旁边布置 Helper。测试区可保留已有图例和可见说明。

## 本轮不做 Helper 的位置

- **固件升级 IAP 与 Factory Reset：** 页面已经把重连方式、擦除范围和确认操作直接写出来。这些安全信息应始终可见；如果将来补充帮助，应是完整步骤或故障排除入口。
- **诊断页的 Schema、Q15、闪存槽位等：** 它们是状态与排障数据，不是用户要调的配置。先保留现有说明，另做诊断术语表更合适。
- **外置 ADC、FPC4、U18 等禁用选项：** 已写明“后续固件开放”，不再用弹窗重复。
- **页面大标题与重复标签：** 只在可改变行为的控件旁放 Helper。R05、R07 等同一设置在多个页面出现时使用同一个说明。

## 已采用的实现方式

1. 确认的 ID、中英文标题与解释集中在 `src/help-content.js`。页面只放 `HelpTip` 和稳定 ID；改文案无需逐页替换。
2. 按**设置 ID**挂载，不按翻译后的可见词句匹配。同一设置在系统页和附件中心复用内容。
3. 弹窗随当前语言自动更新，并避开 DOM 翻译观察器的二次改写。测试会核对文档中每个 ID 的双语文案和页面放置位置。
4. 桌面支持悬停、点击和键盘聚焦；触屏点击打开。点击后可保持，Esc、点外部或换页关闭。弹窗优先显示在按钮上方，减少对输入控件的遮挡。
5. 安全警告与危险操作确认继续常显。按键、形状和校准等已排除的候选项没有加入 Helper。
